## Limits and delivery

This is an optional pack prepared for draft delivery. The plan owner chose Free access for this pack only. This does not change Pro authoring, Pro community exchange, helper requirements or the access policy of the original packs. No live download or installed availability is claimed.

A source-matched app and helper compiled catalog must recognize `donutstudio-demo-visualizers-v1`. Older binaries do not recognize this identity. Publication waits for that build and the actual compatibility and delivery policy. Installation uses the existing shader-pack installer and its one-directory flattening behavior.

The review covered sampled Linux product viewport frames. It did not certify default/reset fidelity, native controls, GPU hardware, performance or other platforms. Existing thumbnails are retained as source metadata, not new renders or acceptance evidence. Authored/imported execution restrictions and exact compiled identity, semantic-kind and source-hash checks still apply.
