# Vidvox ISF Originals

The official **Vidvox ISF-Files** collection repackaged as an DonutStudio shader pack —
327 Interactive Shader Format (ISF 2.0) shaders for the Media Machine:

- **49 generators** — standalone, clock/time-reactive visual sources (plasmas,
  noise fields, geometry, test patterns) you can drop straight onto the timeline.
- **278 filters** — effects that process an input clip (color, distortion, blur,
  glitch, halftone, kaleido, geometry warps, transitions).

Each shader's `kind` (`generator` / `filter`) and original `CATEGORIES` /
`CREDIT` are preserved in `pack.json`. Filters declare `needs: ["an input image
/ clip"]`. Vertex companions (`.vs`) are shipped alongside their `.fs` and loaded
automatically by the ISF runtime.

## Provenance / regeneration

`pack.json` was generated by walking `ISF/*.fs`, parsing each ISF JSON header for
`DESCRIPTION` / `CREDIT` / `CATEGORIES`, and classifying generator vs. filter by
whether the shader declares a `TYPE:"image"` input. The shaders are upstream ISF
works (unmodified); only the DonutStudio `pack.json` manifest is new.
